VM Projects

Trang này không chứa nội dung. Nó đọc thẳng từ repo private của bạn trên GitHub bằng token bạn dán vào. Token chỉ lưu trên thiết bị này.

Cách tạo token (một lần)
  1. Mở github.com/settings/personal-access-tokens/new
  2. Expiration: chọn thời hạn (ví dụ 1 năm).
  3. Repository access: Only select repositories → chọn vm-projects.
  4. Permissions → Repository permissions → Contents: Read and write (chỉ đọc thì chọn Read-only, khi đó không tick hay sửa được).
  5. Bấm Generate token, copy chuỗi github_pat_… và dán vào ô trên.
